Binary Search Tree Visualizer

Insert and delete keys in a plain, unbalanced BST. For every node x, everything in its left subtree has key < x.key, and everything in its right subtree has key > x.key — strictly, so duplicate keys are rejected. Unlike the Red-Black tree, there's no rebalancing here, so a bad insertion order can skew the tree into a chain.
